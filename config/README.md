# Configuração local

firebase.local.json contém as opções web fornecidas pelo proprietário. Não está conectado ao app vazio. O escape Markdown antes do underscore da apiKey foi normalizado para um underscore literal; verificar contra o console antes da integração.

Ler harness/FIREBASE.md. Não copiar a configuração para Obsidian, prompts ou logs. Não confundir configurações públicas do cliente com credenciais administrativas. Não adicionar service-account, segredo OAuth, tokens ou senhas aqui.
